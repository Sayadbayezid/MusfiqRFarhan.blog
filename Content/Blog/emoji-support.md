Emoji can be enabled in a Hugo project in a number of ways. :zap:

## How to use Emoji

To enable emoji globally, we have already set `enableEmoji: true` in our site's configuration. Now you can type emoji shorthand codes directly in your blog posts.

For example:
*   Running fast :runner:
*   Celebration :tada:
*   Tech support :computer:

The [Emoji cheat sheet](http://www.emoji-cheat-sheet.com/) is a useful reference for emoji shorthand codes.
